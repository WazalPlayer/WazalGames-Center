📋 КРАТКИЙ ЧЕКЛИСТ ТОГО ЧТО ОСТАЛОСЬ

Это ВСЁ что тебе нужно сделать:

□ 1. Собрать Firebase ключи (5 мин)
     https://console.firebase.google.com

□ 2. Создать GitHub токен (2 мин)
     https://github.com/settings/tokens

□ 3. Одна команда (всё автоматизировано):
     node scripts/setup-firebase-github.js

□ 4. Запустить:
     npm run dev

□ 5. Создать себе роль админ в Firebase (1 мин)
     - Добавить поле: role = "admin"

□ 6. Перейти на /admin

□ 7. Загружать игры!
