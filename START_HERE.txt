🚀 ТРИ КОМАНДЫ И ГОТОВО:

1️⃣  Получи ключи Firebase (5 минут)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Перейди сюда: https://console.firebase.google.com
1. Нажми "Создать проект"
2. Назови: "wazalgames-center"
3. После создания нажми на </>
4. Скопируй конфиг (все ключи)

Сохрани эти данные:
- API Key
- Auth Domain
- Storage Bucket
- Messaging Sender ID
- App ID

2️⃣  Создай GitHub токен (2 минуты)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Перейди сюда: https://github.com/settings/tokens
1. Нажми "Generate new token"
2. Назови: "wazalgames"
3. Выбери: repo, workflow
4. Скопируй токен
⚠️  СОХРАНИ! Больше не увидишь!

3️⃣  Одна команда - всё настроится!
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

cd "E:\WazalGames Center"
npm install
node scripts/setup-firebase-github.js

Введи те ключи что собрал выше ☝️

Скрипт автоматически:
✅ Обновит все конфиги
✅ Инициализирует Git
✅ Создаст репозиторий на GitHub
✅ Загрузит все файлы

📱 ЗАПУСК ПРИЛОЖЕНИЯ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Откроется: http://localhost:5173

1. Создай аккаунт со своим email
2. После входа ты НЕ сможешь попасть в /admin
3. Нужно сделать себя админом!

🛡️  КАК СДЕЛАТЬ СЕБЯ АДМИНОМ (1 минута)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Перейди в Firebase Console
2. Выбери свой проект
3. Firestore Database
4. users collection
5. Нажми на документ с твоим email
6. Edit
7. Добавь новое поле:
   Поле: role
   Значение: admin
8. Save
9. Обнови страницу приложения

ТЕПЕРЬ У ТЕБЯ ЕСТЬ ДОСТУП К /admin!
